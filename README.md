# Emberfall Vale

A small open-world 3D RPG that runs in the browser. It's built with [three.js](https://threejs.org/) and lives in a single `index.html` file.

## Play

Open `index.html` in a browser, or turn on GitHub Pages (Settings → Pages → Deploy from branch → `main`, root folder) to get a playable link.

## Controls

| Key | Action |
| --- | --- |
| W A S D | Move (hold Shift to sprint) |
| Mouse drag | Turn the camera (scroll to zoom) |
| Click / F | Basic attack |
| Space | Jump |
| E | Talk or pick herbs |
| Q | Drink a potion |

On phones and tablets you get an on-screen stick and buttons.
